The problem

Up to 3 hours

to review one company's financials and build a credit spread by hand

  • Key 10-K/10-Q statements into a spread, build last-twelve-months figures, adjust for leases
  • Compute ratios, map them to ratings, find peers, read the debt notes, check the economy
  • Private borrowers arrive as PDFs in their own format, often unaudited, with no comps on hand
  • Most of the time goes to gathering and calculating, not judging, and that's where errors creep in

Safety: 17/17 tests pass

  • Prompt injection: instruction-like text stripped from filings and uploads; agents have no tools
  • Hallucination: quotes must be in the filing, numbers in the brief, or the answer is retried
  • Loops: 3 attempts, then escalate to the Manager; failed tokens still counted
  • Overspend: 40k per run, 400k per day, rate limits, cache
  • Forged inputs and hostile files: server-side allow-lists; files checked by content; macros and PDF scripts refused
  • Bad data: balance sheet must balance, or a red flag is raised
